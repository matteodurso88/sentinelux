# Sentinelux v0.1.0-alpha.1 — first public alpha

**Status:** [GitHub prerelease published](https://github.com/matteodurso88/sentinelux/releases/tag/v0.1.0-alpha.1) on 2026-10-10. Python package version: `0.1.0a1` (PEP 440); tag: `v0.1.0-alpha.1`. This document also preserves the original readiness checklist and the fact that full Dell automated test logs were not provided.

## Highlights

- Compact GTK 3/AppIndicator system tray for CPU usage, coherent RAM pressure,
  swap and hottest CPU temperature.
- Optional CPU Package temperature and a bounded, scrollable window showing
  all selected CPU thermal sensors with live updates.
- Separate per-core sensor count (the Package is **not** counted as a core).
  Human-friendly ordinal names (Core 1…N) preserve original Linux hwmon
  labels in tooltips. E.g. 14 core readings + one Package = 14 cores, 15
  temperature readings.
- Configurable warning, critical, reminder and recovery desktop alerts.
- Optional preventive suspend/hibernate requests via systemd-logind (off
  by default), with readable kernel critical thermal trip point.
- Read-only fan telemetry (RPM, PWM and mode where the kernel exposes them).
- Per-user installation and XDG autostart, and a `--once` JSON snapshot.

## Scope and safety

- **No fan-speed control.** Experimental PWM presets and the privileged
  `pkexec` fan helper are *not* part of this release. Fan RPM/PWM fields are
  readings, not proof of firmware fan-control support.
- Fan channels can be duplicate representations of one physical fan
  (e.g. Dell `dell_ddv` and `dell_smm`).
- Thermal alerting cannot replace firmware, kernel or hardware safety
  protections. Preventive sleep actions depend on local authorization and
  platform support.
- The application has no network telemetry or cloud sync.

## Installation from source (Debian-family desktops)

Prerequisites: Python 3.10+, GTK 3, PyGObject, psutil, libnotify,
Ayatana AppIndicator or its legacy equivalent, and an AppIndicator-compatible
tray. No prebuilt `.deb`, AppImage, signed binaries or APT repository.

```bash
git clone https://github.com/matteodurso88/sentinelux.git
cd sentinelux
# Once the prerelease exists, use the published tag:
# git checkout v0.1.0-alpha.1
./scripts/install-deps-debian.sh
./scripts/install-user.sh
~/.local/bin/sentinelux --version
~/.local/bin/sentinelux --debug
```

For development from the candidate branch (until tag publication),
`git switch work/first-prerelease-v0.1.0-alpha.1` before running the scripts.

To remove a previously installed experimental privileged fan helper (if any),
run `./scripts/uninstall-fan-helper.sh`. The alpha does not install it.

## Known limitations

- Pre-release quality; tested devices/desktops are limited. Not all Linux
  systems expose CPU temperatures, RPM sensors or a supported tray.
- No advanced dashboard, history, battery/storage/network monitoring,
  per-core CPU load graph, or fan curves.
- Runtime interface is Italian; the documentation is Italian and English.
- Packaging is per-user source installation. No update manager.
- Preventive hibernation/suspension is optional and cannot be guaranteed.
