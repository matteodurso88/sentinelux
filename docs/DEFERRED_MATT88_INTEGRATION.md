# Deferred matt88.it integration

The Sentinelux product integration in the main `matteodurso88/matt88` repository remains intentionally separate from the Linux application development.

A verified bilingual handoff dossier is now maintained at:

- `docs/public/sentinelux-matt88-dossier.md`

The dossier covers public copy, product status, technical evidence, structured data, media requirements and publication blockers. It does not modify the matt88.it repository and does not imply that a public product page or downloadable release already exists.

Before implementing the site integration, the maintainer must confirm the blockers listed in section 15 of the dossier, especially the consolidated public commit, the availability wording, sanitized media, tested distribution details and release strategy.
