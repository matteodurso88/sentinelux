# Deferred matt88.it integration

The Sentinelux product integration in the main `matteodurso88/matt88` repository is intentionally deferred. It must not block or slow the initial personal Linux build.

When resumed, the integration should cover:

- localized Italian and English product metadata;
- localized product-page content;
- software index visibility for a public open-source product;
- source-code and license calls to action;
- GitHub Releases linkage;
- product-specific visual assets supplied manually by the maintainer;
- compatibility with the existing generic product-page architecture.

No matt88.it repository changes belong in the Sentinelux bootstrap patch.
